# Goat Multi-tissue Transcriptomic Atlas

This repository contains the plotting scripts and associated input data used to generate the main figures in the manuscript describing the goat multi-tissue transcriptomic atlas.

## Repository structure

- `scripts/`: Scripts used to generate the main figures.
- `data/`: Input tables and summary data required to reproduce the figures.

## Requirements

The required software and package versions are documented in the corresponding scripts.

## Usage

Run the scripts in `scripts/` using the input files provided in `data/`. Each script is named or annotated to indicate the corresponding figure in the manuscript.

## Data availability

RNA-seq and whole-genome resequencing data are deposited in the NCBI Sequence Read Archive under BioProject accessions PRJNA1457892 and PRJNA1457889, respectively.
